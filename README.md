# Комплаенс-карта 2.1

Интерактивная карта санкций против России с поиском, фильтрами, закрытыми рабочими разделами, локальным скринингом по официальным санкционным спискам и календарём контрольных дат.

Сайт публикуется автоматически из ветки `main` с помощью GitHub Actions. Основной адрес:

<https://luxtendebant-ux.github.io/Sanctions_map_v.2.1/>

## Автоматизация

- `deploy-pages.yml` публикует текущую версию сайта в GitHub Pages при каждом изменении ветки `main`.
- `screen-index.yml` дважды в сутки обновляет открытый экспорт карты, календарь и индекс санкционных списков, проверяет структуру данных и сохраняет результаты в репозиторий.
- `map-data-open.json` содержит открытую структурированную выгрузку для аналитических инструментов.
- `deadlines.ics` можно подключить к календарю для контроля сроков.
- `screen-index.json` и `screen-delta.json` используются для локального скрининга на странице: введённые пользователем данные не отправляются на внешний сервис.

## Локальная проверка

```powershell
python -I .github/screen/export_open_map.py index.html map-data-open.json
python -I .github/screen/build_deadlines_ics.py map-data-open.json deadlines.ics
python -I .github/screen/validate_index.py
```

Расширенный браузерный тест находится в `tools/smoke.cjs` и запускается при установленном Playwright. Для положительных тестов закрытых разделов путь к локальным ключам передаётся только через переменную `CM_KEY_DIR`.

## Конфиденциальные файлы

Файлы с паролями хранятся только локально в каталоге `Complaince_map_2.1` и исключены из Git правилами `.gitignore`. Не добавляйте их в публичный репозиторий и GitHub Actions secrets без отдельной необходимости.
